# Bolt / spark SVGs (fix.md item 30)

All files: `viewBox="0 0 64 64"`, no width/height, `currentColor` fill and stroke, round joins and caps, no fonts or rasters. Recolour with CSS `color`. Suggested yellow: `#F4D03F` (Sparky's bell) or `#ffb703` (app accent); on the cream background add a dark outline or use `#fb8500` for contrast.

| File | What it is | Recommended placement |
|---|---|---|
| `bolt.svg` | Solid rounded bolt, the main icon | Next to the "Sparky's Snap Lab" title in the header, ~24 px; also as list/step bullet |
| `bolt-chunky.svg` | Fatter, softer bolt (extra option) | Alternative to `bolt.svg` if it feels too sharp for 5-year-olds; good at 16-24 px |
| `bolt-outline.svg` | Outline-only bolt (extra option) | "Not yet powered" / locked / disabled state |
| `bolt-spark.svg` | Bolt with 5 short rays | Beside Sparky in the header (~96 px), and on the celebration / success screen |
| `zap-1.svg` | Four-point rounded twinkle | Scatter, 12-20 px, around Sparky or the header edges |
| `zap-2.svg` | Round-capped zigzag zap | Scatter, 16-24 px; "electricity flowing" next to circuit pieces |
| `zap-3.svg` | 5-ray burst | Scatter, 20-32 px; pop it on tap-Sparky and on celebration |

Scatter tip: rotate and vary size (12 / 20 / 32 px) rather than repeating one size.
